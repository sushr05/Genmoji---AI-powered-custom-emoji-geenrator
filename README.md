# Genmoji---AI-powered-custom-emoji-geenrator
Built a full-stack system combining LLM-based prompt expansion (DeepSeek) and image generation (LoRA-tuned Stable Diffusion XL) to create high-fidelity, context-aware emojis from natural language input. Deployed inference via FastAPI and Hugging Face; optimized for real-time usage and scalability.
